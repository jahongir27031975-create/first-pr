# Мерос анкета

Ўзбекистон Республикаси Фуқаролик кодексининг V бўлими («Мерос ҳуқуқи», 1112–1157-моддалар) асосида меросхўрлар таркиби ва улушларини аниқловчи бир саҳифали веб-дастур.

## Ишга тушириш

`index.html` файлини браузерда очинг (`engine.js` ёнида бўлиши керак). Интернет ва сервер талаб қилинмайди, маълумотлар фақат браузерда сақланади.

## Нималарни ҳисоблайди

| Масала | Модда |
|---|---|
| Қонун бўйича навбатлар: 1-навбат (фарзандлар, эр/хотин, ота-она), 2-навбат (ака-ука, опа-сингиллар, бобо-бувилар), 3-навбат (амаки, тоға, амма, холалар), 4-навбат (6-даражагача қариндошлар, яқин даража устун), 5-навбат (қарамоғидагилар) | 1134–1139 |
| Тақдим этиш ҳуқуқи: тўғри чизиқда чексиз, ён чизиқда жиянлар ва амакиваччалар | 1140 |
| Меҳнатга лаёқатсиз қарамоғидагилар (бирга яшаш шарти, 1/4 чегара) | 1141 |
| Мажбурий улуш — қонун бўйича улушнинг камида ярми | 1142 |
| Эр-хотин умумий мулкининг ½ қисмини мерос массасидан ажратиш | 1114, 1143 |
| Номуносиб меросхўрлар, меросдан воз кечиш, улушларнинг ўсиши | 1119, 1147, 1154 |

Улушлар аниқ каср (масалан, 1/8), фоиз ва сўмда чиқарилади; ҳар бир меросхўр учун асос ва модда кўрсатилади. Анкетани JSON га сақлаш/юклаш ва чоп этиш (PDF) мумкин.

## Чекловлар

Мерос трансмиссияси (1140-1), муайян шахс фойдасига воз кечиш (1148), меросхўрни қўшимча тайинлаш (1122), васиятнинг ҳақиқийлиги (1130) ва мулкни натура шаклида бўлиш (1150, 1153) автоматик ҳисобланмайди. Мажбурий улушни қоплаш манбаи (аввал васият қилинмаган, сўнгра васият қилинган қисм) — услубий ёндашув, чунки 1142-моддада тартиб белгиланмаган.
